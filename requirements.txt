# Backend and tooling dependencies for the Bug Reproduction & Triage Assistant.
#
# All Python work happens inside the project virtual environment. Create it
# once, then activate it at the start of every session:
#
#   python -m venv .venv
#   .venv\Scripts\activate           (Windows)
#   source .venv/bin/activate        (macOS and Linux)
#   pip install -r requirements.txt
#
# Direct dependencies are pinned so that all ten of us install the same
# versions. Transitive dependencies are resolved by pip.
#
# To change a version: edit it here, reinstall, run the backend checks, and
# say what changed and why in the pull request. Do not upgrade a pin as a
# side effect of unrelated work.
